WHOLE DONUTS UNIVERSE

Start here: the public system map.

Whole Donuts Universe is the one public entry for practical learning, creative exploration, and community care. Pick the path that is useful today; every public path can stand on its own.

1. Start with community

Use the four-tap +U gateway, The Table, or the The Counter. The gateway's temporary choices are not stored, submitted, tracked, or used as a profile.

2. Use the +U Library

The +U Library provides editable next-step, share-a-crumb, and build-your-table templates. They are available now to copy and adapt without creating an account.

3. Explore and lead

+U World is an optional visual studio. The Ambassador Path is an open direction for creative, trade, community, and business leadership; it is not an application, certification, or offer of employment.

4. Carry a reviewed crumb

A crumb is original or permitted public material someone else can use. The public site does not accept submissions. Prepare material with a template and submit only through an owner-approved channel when one is available; human review comes before publication.

What is available now

The public entry, +U Library, +U World, reviewed protocol, Whole Donuts and TNC community paths are available to explore. The Goods Window is browse-only: no store or commerce destination is active until an owner verifies one. Optional support is separate from merchandise and is always a deliberate external choice.

What is not available

There are no accounts, sign-in links, profiles, submissions, automatic intake, or automatic publication on this public site. Crumb submission remains unavailable until an owner approves a reviewed channel. The browser-only review queue is a curated metadata shortlist, not a publication tool. Sunshine references remain metadata-only and need owner review; WHNutz and merch materials are not public-source candidates without explicit rights and safety review.

Privacy and publication boundaries

The gateway keeps four choices only in temporary page state and clears them on restart, skip, back, or onward navigation. The site does not collect names, email addresses, face images, photos, exact age or birth date, location, sensitive data, repository contents, secrets, or operational configuration. It has no analytics, tracking, profiling, network scanning, automatic content intake, automatic publication, automatic GitHub actions, or automatic merges. See the public system policy and maintainer curation process for the source-of-truth map.

Growing with care

Future updates can add only eligible, rights-reviewed public material through the documented human process. They will not turn browsing into a profile or promise a feature before it exists. See release notes for that format.
